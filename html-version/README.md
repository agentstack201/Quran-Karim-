# فهرس السور — نسخة HTML/CSS/JS خام

نسخة مستقلة من صفحة "فهرس السور" في تطبيق **تلاوة**، مبنية بـ HTML و CSS و
JavaScript خام بدون أي إطار عمل (لا React، لا Next.js، لا مكتبات خارجية سوى
خطوط Google Fonts). أُعدّت كمتطلب أكاديمي منفصل عن تطبيق الويب الرئيسي.

## المحتوى

- `index.html` — بنية الصفحة
- `styles.css` — التنسيق، منقول عن نظام تصميم التطبيق الأصلي (الألوان، الخطوط، شارة رقم السورة)
- `script.js` — منطق البحث والترتيب والترشيح وفتح تفاصيل كل سورة
- `data.js` — بيانات السور الـ١١٤ (مأخوذة من `src/data/chapters.json` في المشروع الأصلي)

## التشغيل

لا حاجة لأي تثبيت أو بناء. يكفي فتح `index.html` مباشرة في المتصفح، أو تشغيل
خادم ملفات ثابتة بسيط من هذا المجلد، مثال:

```bash
python3 -m http.server 8000
```

ثم زيارة `http://localhost:8000`.

## المزايا

- بحث فوري بالاسم أو الرقم (مع تجاهل التشكيل واختلاف رسم الهمزة)
- ترتيب حسب المصحف أو ترتيب النزول أو عدد الآيات
- ترشيح حسب مكان النزول (مكية / مدنية)
- فتح كل بطاقة لعرض تفاصيل إضافية (الجزء، الصفحات، عدد الأركاع، البسملة)
- دعم الوضع الليلي تلقائياً حسب إعداد النظام
- تصميم متجاوب لجميع أحجام الشاشات
